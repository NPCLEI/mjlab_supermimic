### 3.3 重构期间抓到的 bug

| bug | 症状 | 修法 |
|---|---|---|
| 注册表按函数对象匹配 | tracking 的 8 项函数在引擎自己的 reward 模块里，`getattr(mjlab.mdp, ...)` 全 None → 7 项被误判成 learned，奖励差 5e-2 | 改为**按 term 名字注册** + 绑定函数对象 |
| `RunningNorm` 被非有限样本污染 | 速度任务摔倒产生 NaN 状态 → running 均值/方差永久 NaN → 后续 loss 全 NaN | 统计前 `nan_to_num`，forward 同样 sanitise |
| `WmSpec` 未声明 runner 契约标志 | `auto_reset` 默认 False 而 env 也复位 → 双重复位，episode 变 1 步、回报 −4.2 | 从 `env.cfg.auto_reset` 与是否存在 `replay` recorder 推导 |
| command 任务未建 heads | 速度任务 6 项全被判 learned（未训练 → ≈0）| `_build_heads` 对非 tracking 任务构造 `VelocityHeads` |
| 引擎 `training/loop.py` 用行数当门限 | resume 时空缓冲立刻更新 → `replay buffer has no sampleable rows yet` | 改用时间深度 `buffer.ptr.min()` |
| `WindowBatch.r_terms` 字段顺序 | 有默认值字段排在无默认值之后 → dataclass `TypeError` | 移到末尾 |
| `r_terms` 算出但没传进 `buffer.add` | learned 头永远没有监督信号 | 补 kwarg |
| `SuperMimicCfg` 缺 `learned_cfg` | `update()` 收到 None → `AttributeError` | 加字段 |

## 6. 速度追踪（10-29 → 10-30）

### 6.1 测量方法学（两次错误，都已修）

1. 误差曾对固定 `cmd = 0.8 m/s` 计算，而环境指令是 ±1 m/s 随机重采样 → 指标无效。
   正确做法：`|v_xy − cmd_xy|`，用**实际指令**。
2. 每个 ckpt 曾用不同的随机指令序列评测 → 同一 ckpt 可测出 8% 或 16%。
   正确做法：固定 `cfg.seed` + `torch.manual_seed`。

### 6.2 从零训练（固定种子，可复现）

| ckpt | 迭代 | 墙钟 | ±0.2 达标 | `|v−cmd|` | 集长 |
|---|---:|---:|---:|---:|---:|
| 20,000 | 20k | 0.99 h | 8.3% | 0.758 | 2.07 s |
| 40,000 | 40k | 1.92 h | 10.3% | 0.754 | 2.65 s |
| 48,000 | 48k | 2.30 h | 6.1% | 0.800 | **4.97 s** |

**集长翻倍但达标率不升** → 学会平衡，没学会跟速度。

### 6.3 PPO 对照

| 迭代 | 墙钟 | ±0.2 |
|---|---:|---:|
| 2,700 | 0.9 h | 15.9% |
| 4,000 | 1.3 h | 12.2% |

### 6.4 附录 B 编码器（10-30）

实现：`Policy.encoders["velocity"]`（930+3 → 256,256 → 32 → tanh，指令按 `[2.0,1.32,3.35]` 缩放）、
930 维引擎布局历史、3 维指令目标、672 条件评测器。

| 配置 | 结果 |
|---|---|
| decoder 冻结（12k 迭代）| train_ret 0.136、集长 0.66 s、**0/64** |
| encoder+decoder 联合（16k）| train_ret 0.247、集长 ~10 s、**0/64** |
| + 世界模型从追踪 run 热启动 | `nse1 nan`、崩溃（ξ 布局不兼容）|
| + 灌入 PPO 走路数据 | `train_ret −4.21`、崩溃（片段与超时复位不连续）|

**上限是实测的**：世界模型动作敏感度 11.6%（`real dv [-0.005,+0.003,−0.199]` vs `wm dv [-0.003,+0.006,−0.022]`）。
社区中报出 652/672 的复现是在**已见过走路的同一个世界模型**上继续训练编码器；本仓库每次 run 新起世界模型。

## 8. 被推翻的结论（重要）

| 曾给出的结论 | 推翻依据 |
|---|---|
| "速度追踪学不出来" | 正确指标下能部分跟踪（6–10%），集长翻倍 |
| "16% 超过 PPO" | 固定种子后是 8–10%，16% 是指令序列随机造成的噪声 |
| "世界模型敏感度 0.116 → 没梯度、学不会" | 只解释"学得慢"；从零训确实在学 |
| "奖励注册完整" | 速度任务当时只注册 6/13，7 项 learned 是随机噪声（已修：删除不可学项）|
